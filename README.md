# cadastro de clientes e pedidos em php

exercício de sala de aula que fiz no começo dos meus estudos de php. é um sistema simples de cadastro de clientes e pedidos, feito para praticar os fundamentos da linguagem.

## funcionalidades
- cadastro de clientes
- listagem de clientes
- cadastro de pedidos
- listagem de pedidos
- edição e exclusão de registros

## estrutura
o exercício é dividido em páginas, cada uma com uma função:
- páginas de cadastro, com formulários para enviar os dados
- páginas de listagem, que mostram os dados salvos
- arquivos de apoio, como a conexão com o banco de dados

## o que aprendi
- como funcionam formulários e envio de dados
- como conectar o php a um banco de dados
- como cadastrar, listar, editar e excluir registros (crud)
- como organizar um exercício em várias páginas
- que ainda tenho muito a melhorar, como validação e segurança
